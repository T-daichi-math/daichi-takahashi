題名：情報の鮮度を考慮したシャノンの情報量<br>
氏名：髙橋大地(6807020B)<br>
概要：本講義で学習したシャノンの情報量をもとに、時間が経過するにつれて情報量が減少する(情報が風化する)場合を考慮にいれた情報を定義する。具体的には既存のシャノンの情報量の式をe^(-λt){ただしλ,tは正の実数}を掛けることによって時間が経過するにつれて情報量が小さくなるというものである。この定義のポイントとして、時刻t=0の場合は既存のシャノンの情報量となることと、無限時間経過した場合(λ≠0)はどれも情報量がゼロになる点である。時間の項を導入することによって、情報の鮮度を反映させることができより日常生活に適した情報が定義できるのではないかと考える。

プログラムの内容：<br>
初めに時間が経過するにつれて情報量が減少するシャノンの情報量について定義を行った。既存のシャノンの情報量にe^(-λt)を掛けることで新たな情報量を定義している。式を用いて書くと、I(p,t) = -log2(p)*exp(-λ*t)である。ここでpは事象が発生する確率、tは経過時間、λは減衰定数としている。plot_figure1はpが0.01,0.05,0.2,0.5の場合時間が経過するにつれて情報量がどのように減少するのかを表したグラフを描画するコードであるこの時λは0.5として確率の違いによる情報量の時間変化を見ている。plot_figure2は確率を0.05に固定しλを1.5,0,5,0.02の3つの場合で考えている。それぞれの時間経過によってどのように減少するのかを表したグラフを描画するコードになっている。ここでλ=1.5はSNSの流行など流行り廃りが早い内容を、λ=0.5はニュースのデータなど情報の鮮度が中程度の内容を、λ=0.02は数学の定理など情報量が時間経過によってほとんど変化しない内容を想定している。最後のplot_figure3は時間経過によって新しい情報が入り情報量が増加する場合のグラフを描画するコードである。今回は2単位時間ごとに情報量が増加する場合を想定している。今回はこれらの3つのグラフが次々に描画されるコードを作成した。

考察と分析：<br>
今回私は、時間に依存する情報量の定義を行った。シャノンの情報量にe^(-λt)を掛ける単純な定義ではあるものの、この定義によって時間による情報の鮮度を考慮に入れることができたのではないかと考えている。この定義はt=0又はλ=0の場合はシャノンの情報量と全く同じ式の形になり扱いやすい定義である。λ=0とは時間経過しても全く情報量が変わらないつまり普遍的事実等がこれに当たると考えている。いつの時代でも変わらない普遍的内容は情報量が変わらないという自身の直感と式が適切に反映されているように思える。また、差ではなく積で定義することにより、情報量が正の値のみとることとなる。これはシャノンの情報量と同じ性質を引き継げており自然な拡張ができているのではないかと思う。また、グラフの概形を見てみるとe^(-λt)を掛けていることにより、初期時刻からの減少量が一番大きく、徐々に減少量が緩やかになっていることが読み取れる。減少量が一定にはならないような工夫をここでは行った。従来の定義と比べ、時間経過による価値の喪失や、SNSの流行の情報や数学の定理、天候などの分野ごとに違い(λ)を反映することができることがこの定義の最大の利点である。
